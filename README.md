# AI 번역 & 문장 검토기 (Chrome Extension)

AI API를 활용하여 웹페이지에서 드래그한 문장을 손쉽게 번역하고, 문법 오류 및 원래 의도에 맞춘 자연스러운 대체 문장을 추천받을 수 있는 크롬 확장 프로그램입니다.

---

## 🌟 주요 기능

1. **선택한 문장 번역하기 (마우스 우클릭)**
   - 웹페이지에서 드래그한 텍스트를 마우스 우클릭하여 즉시 번역.
   - 메인 번역문 외에도 **상황/뉘앙스별 추천 대안 번역 문장 2~3개**를 함께 제공 (각각 원클릭 복사 지원).
   - 어휘 팁과 뉘앙스 차이를 정리한 **참고 노트**를 사용자가 지정한 **설명 언어(C)**로 제공.

2. **선택한 문장 검토하기 (마우스 우클릭)**
   - 문법, 띄어쓰기, 어색한 표현을 정밀하게 교정(Proofreading).
   - **작성자의 원래 의도를 유추**하여 상황에 맞는 추천 대안 문장 2~3개 제안 (일상 회화체, 격식 있는 비즈니스 표현 등).
   - 문제점 분석 리포트 및 피드백을 지정한 결과 언어(B)로 100% 제공.

3. **기능별 언어 분리 설정**
   - **번역 기능**: 출발 언어(A), 도착 언어(B), 참고 노트 설명 언어(C) 분리 설정.
   - **검토 기능**: 검토 대상 언어 후보(A, 최대 2개), 피드백 출력 언어(B) 설정.

4. **웹페이지 스타일 완벽 격리 (Shadow DOM)**
   - 페이지 CSS와의 충돌이 전혀 없는 플로팅 오버레이 카드 UI.
   - 마우스 드래그로 위치 이동 가능, `Esc` 키로 닫기 지원.

---

## 🚀 설치 및 등록 방법

별도의 복잡한 빌드 과정 없이, Chrome 브라우저에 바로 로드하여 사용할 수 있습니다.

1. Chrome 브라우저를 열고 주소창에 `chrome://extensions`를 입력하여 이동합니다.
2. 우측 상단의 **'개발자 모드(Developer mode)'** 스위치를 켭니다.
3. 좌측 상단의 **'압축해제된 확장 프로그램을 로드합니다(Load unpacked)'** 버튼을 클릭합니다.
4. 이 프로젝트의 폴더 (`D:\git\chrome-extension-grammar`)를 선택합니다.
5. 확장 프로그램 목록에 **'AI 번역 & 문장 검토기'**가 추가됩니다.

---

## ⚙️ 설정 방법

1. 브라우저 우측 상단 퍼즐 아이콘(확장 프로그램)에서 **AI 번역 & 문장 검토기**를 클릭합니다.
2. **'⚙️ 환경설정'** 버튼을 누르거나, 확장 프로그램 우클릭 후 '옵션'으로 들어갑니다.
3. **API Key**: [Google AI Studio](https://aistudio.google.com/app/apikey) 등에서 발급받은 API 키를 입력하고 **'API 키 검증'** 버튼을 눌러 확인합니다.
4. **AI 모델 선택**:
   - `gemini-3.5-flash-lite` (기본값, 추천)
   - `gemini-3.1-flash-lite`
   - `gemma-4-26b-a4b-it`
   - `gemma-4-31b-it`
   - 또는 **직접 입력(Custom)** 지원
5. **번역 기능 언어 설정**:
   - 출발 언어 A (원문): `언어 자동 감지` 또는 특정 언어 선택
   - 도착 언어 B (번역 결과): 원하는 번역 결과 언어 선택 (예: `한국어`)
   - 설명 언어 C (참고 노트 및 라벨): 참고 노트 및 추천 대안 스타일 라벨을 출력할 언어 선택 (기본값: `한국어`)
6. **검토 기능 언어 설정**:
   - 검토 대상 언어 후보 A (최대 2개 선택): 예) `영어`, `한국어`
   - 설명 및 피드백 출력 언어 B (1개 선택): 유추된 의도, 문법 오류 분석 및 종합 코멘트를 전달받을 언어 (예: `한국어`)
7. **'설정 저장'**을 클릭합니다.

---

## 📖 사용 방법

1. 아무 웹페이지나 열고 번역 또는 검토하고 싶은 텍스트를 마우스로 드래그합니다.
2. 드래그된 영역 위에서 **마우스 우클릭**을 합니다.
3. 컨텍스트 메뉴에서 원하는 기능을 선택합니다:
   - 🌐 **선택한 문장을 번역하기**
   - ✍️ **선택한 문장을 검토하기**
4. 화면에 나타나는 AI 카드에서 감지된 언어와 번역/추천 제안을 확인하고, **'복사'** 버튼으로 손쉽게 클립보드에 복사해 사용하세요.
