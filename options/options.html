AI 번역 & 문장 검토기

확장 프로그램 환경설정

1. AI API 및 모델 설정

AI 서비스(Google AI Studio 등)에서 발급받은 API 키를 입력해 주세요. API 키 발급받기 →

2. 번역 기능 언어 설정

'선택한 문장을 번역하기' 실행 시 적용할 출발 언어(A), 도착 언어(B), 그리고 참고 노트를 출력할 설명 언어(C)를 설정합니다.

번역문의 뉘앙스, 주요 어휘 팁 및 추천 대안 문장의 스타일 라벨을 표시할 언어입니다.

3. 검토 기능 언어 설정

'선택한 문장을 검토하기' 실행 시 적용할 검토 대상 언어 후보(A)와 설명 출력 언어(B)를 설정합니다.

드래그한 문장이 어떤 언어로 쓰였는지 식별할 후보 언어를 최대 2개까지 선택하세요.

유추된 의도, 문법 오류 분석 및 종합 조언을 전달받을 언어를 선택하세요.
